# MMS dashboard UI implementation

Goal: finish the existing Streamlit workflow as a Vietnamese inventory decision
workspace using the current MMS service and source/provenance boundaries.
The user requested implementation directly; retain Streamlit and the feature branch.

## Design

Use a restrained light dashboard, deep teal sidebar, clear typography and native
tables/charts. Sidebar parameters create 1–4 scenarios; result metrics and six
tabs cover Review, Order, comparison, manager actions, evaluation and saved sessions.
Show synthetic provenance prominently; show numeric risk scores, never implied
calibrated probabilities or automatic purchase instructions. Raw JSON belongs in
optional reproducibility details/downloads. The trained generated app must render
the same UI through the existing injected-runtime entrypoint.
